# 뉴스 분류 라벨 정의서 (2026-09-16 패널 · E5 합의안 실행판)

## ① 목적

세 축(종목 귀속·감성·DART 유형)의 **정확도를 측정**하기 위한 정답(라벨) 표본을 만든다.
수익률 결합은 **0건**(이 표본은 사전등록 1단계 — 「종목 귀속 기사 중 오탐 비율」·「dart_report_type
정밀도」 같은 수익률 무관 지표에만 쓴다). 2단계(수익률 IC 검정)는 Q1 서명 후 별도 사전등록.

## ② 표본 A — 기사-종목 행 (n=450)

- **모집단**: `news` × `news_stock` 조인 행 중 국내 4소스(naver/hankyung/mk/dart), **2026-09-13
  이후**(09-12 사전 교체 a7e497b 이후, 오염분 제외)(E2).
- **층화**: naver 250 / hankyung 90 / mk 50 / dart 60.
- **소스 내 추가 층화**: 기사당 종목수 k=1 : k≥2 = 2:1.
- **추출 SQL 골격** (실행하지 말 것 — 골격만):
  ```sql
  SELECT n.news_id, n.title, n.content, n.source, n.published_at, ns.stock_code
  FROM news n
  JOIN news_stock ns ON ns.news_id = n.news_id
  WHERE n.source = :source
    AND n.published_at >= '2026-09-13'
    -- k=1 / k>=2 층은 news_id 별 stock_code 개수로 사전 분리 후 각각 표본 추출
  ORDER BY random()
  LIMIT :n_per_stratum;
  ```

## ③ 라벨 스키마

**행(기사-종목) 라벨** `(news_id, stock_code, role, direction, strength)`:

| 축 | 값 | 정의 | 예시 |
|---|---|---|---|
| role | 주체 | 기사 핵심 사건의 당사자 | 「아고스, 카자흐 국영기업과 MOU」→175140 주체 |
| | 비교·동종 | 동종업계 비교·특징주 나열 대상 | 특징주 테마 기사에서 언급된 동종 종목 |
| | 출처 | 정보 제공자일 뿐 사건 당사자 아님 | 「키움證 "삼현, 급등…"」→키움증권 출처 |
| | 배경·지수 | 지수·시황 설명 중 예시로 등장 | 「코스피 6,700선 회복」→삼성전자·SK하이닉스 배경·지수 |
| | 나열 | 리스트형 기사에 다수 종목 중 하나로 등장 | 「초고수 장바구니」·「외국인 순매수 상위」 나열 |
| | 오탐 | 회사명과 무관한 일상어 오매칭 | 「파전집…비오는 날 몰린 곳」→NAVER(035420) 오탐 |
| direction | 호재 | 해당 종목에 긍정적 함의 | |
| | 중립 | 함의 없음/불명 | |
| | 악재 | 해당 종목에 부정적 함의 | |
| strength | 강 | 함의가 뚜렷하고 직접적 | |
| | 약 | 함의가 약하거나 간접적 | |

**기사 라벨** `asset_class ∈ {주식, 금리·채권, 환율, 지수·시황}`:
- 예시: 「아고스 MOU」→주식, 「FOMC 관망 속 국고채 금리 하락」→금리·채권,
  「원화 저평가…환율」→환율, 「코스피 6,700선 회복」→지수·시황.

## ④ 라벨 단위·블라인드

- 라벨 단위 = **제목 + 본문 앞 300자**(E1 F2 근거 — 점수 크기가 본문 길이로 갈리므로 관측
  단위를 본문 전체가 아니라 앞부분으로 고정해 라벨 조건을 통일).
- 라벨러에게 **추출 결과(현재 role/related_stocks 값)를 보여주지 않는다** — 블라인드.

## ⑤ 재현율 표본 (별도 150 기사)

- 표본 A 와 겹치지 않는 별도 150건.
- 라벨러가 기사 전체를 보고 `true_subjects[]`(실제 주체 종목 코드 목록)를 직접 채운다 —
  추출 결과를 먼저 보여주면 재현율을 원리적으로 측정할 수 없다(E2).

## ⑥ 일치도 측정

- 표본 A 450건 중 **150건을 2인이 이중 라벨링**.
- **weighted κ (linear)** 로 role·direction·strength 각 축 일치도 산출.
- **κ < 0.6 이면 모델/알고리즘 개선 전에 이 정의서(③ 라벨 스키마)를 먼저 개정**한다.

## ⑦ 표본 B — DART 유형 (n=200)

- 모집단: `news` source='dart', 제목 `[회사명] 보고서명 (부가)` 규격에서 정규식으로 유형 추출.
- 층화: E3 그룹 A~F(자본/계약·제재/정지/조회·실적/정기보고·지분변동·정기/형식·기타) 비중별
  배분 또는 상위 유형 우선 — 실행 시 확정.
- **정밀도 게이트 = 「오답 ≤ 1건」으로 명시**(E5: n=200 에서 정밀도 ≥0.98 판정은 오답 0~1건일
  때만 통과 — 오답 4건이면 Wilson CI 하한이 0.949로 떨어져 게이트 미달).

## ⑧ 정밀도 CI 참고

- E3 계산(수식): n=200, p̂=0.70 → SE 0.0324 → 95% CI ±0.064.
- go/no-go 판정에는 충분하나 **IC_true 점추정에는 부족**(±0.032 이려면 n≈800 필요).
- 층화 시 셀당 표본이 얇아지면 CI 가 급격히 벌어진다(예: 4소스 균등 분할 시 셀당 50 → ±0.13) —
  ⇒ 표본 A/B 를 이 규모로 분리 유지하는 이유.

## ⑨ 목표·게이트

- 주체(role='주체') 정밀도 **0.85** / 기사단위 재현율 **0.70**.
- 게이트: 「재현율 −5%p 이내에서 정밀도 +10%p」 개선이면 통과.

## ⑩ 저장

- `news_label` 롱 테이블(D4 결정). 스키마: `(news_id, axis, key, model, version, label, score, meta)`.
  - `axis`: 'stock_role' | 'sentiment' | 'dart_type' | 'asset_class' 등.
  - `key`: stock_code / sector_key / NULL (기사 단위 라벨은 NULL).
  - `meta` JSONB: in_title/first_para/mentions 등 위치·빈도 보조정보.
- **DDL 실행은 별도 승인 후**(이 문서는 정의서일 뿐 DDL 문서가 아님).
