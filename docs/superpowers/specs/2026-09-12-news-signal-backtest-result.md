# 뉴스 신호 백테스트 — 실행 결과 (2026-09-12)

설계: `2026-09-12-news-signal-backtest-design.md` · 계획: `../plans/2026-09-12-news-signal-backtest.md`

재현 방법 (신호는 `backtest_signal` 에 저장돼 있으므로 측정만 다시 돌리면 된다):

```
python scripts/run_news_backtest.py --start 2026-01-07 --end 2026-09-11
```

신호를 처음부터 다시 만들려면 `--replay --apply` 를 붙인다. 다만 전체 범위를 한 번에 돌리면
장시간 실행이라 시스템 메모리가 빡빡할 때 중단될 수 있다 — 2개월씩 나눠 돌리면 각 청크가
약 70초다(재현은 거래일 단위 커밋이라 나눠 돌려도 결과가 같다).

---

## 답

**뉴스 신호는 다음 수익을 예측하지 못한다.** 부호는 오히려 «약한 음(-)» 이고, 커버리지가
제대로 된 창에서는 0 과 구별되지 않는다.

- `sector_1530`(167 거래일, 횡단면 중앙값 148.5종목) — h1 평균IC **-0.0190**, t -1.43,
  **순열검정 p = 0.084**. 통상 기준으로 0 과 구별되지 않는다. h0 는 -0.0254(t -2.31),
  h5 는 -0.0156(t -1.13).
- `prod_calendar`(160 거래일) — h1 평균IC -0.1053, p = 0.006 으로 «유의해 보이지만»
  횡단면 중앙값이 **8.0종목** 이라 리포트가 ⚠ 를 달아 놓았다. n=8 에서 나올 수 있는 순위상관은
  이산값 몇 개뿐이라 「상관을 쟀다」기보다 「그날 어느 순열이 나왔는지 봤다」에 가깝다.
- **히트율은 세 구간 모두 0.5 미만**(0.418~0.491) — 음의 부호와 일관된다.
- 분위수 스프레드는 ±0.002 수준이고 동점 비율 중앙값이 0.13~0.15 라, 그 작은 스프레드조차
  상당 부분이 동점 처리에 좌우된다.

두 창을 «깨끗한 A/B» 로 읽으면 안 된다. 2026-03~07 국내 언론 공백(3월 0건·4월 83·5월 30·
6월 0·7월 92) 때문에 그 구간 신호가 사실상 DART 단독이고, DART 는 15:30 이후에 쏠려
`sector_1530` 에는 잡히고 `prod_calendar` 에는 상당수가 빠진다 — 두 창은 창 정의뿐 아니라
**코퍼스 커버리지가 다르다**.

## 이 결과를 어떻게 쓸 것인가

지금의 `composite_score` 를 그대로 매수후보 정렬에 쓸 근거는 이 측정에 없다. 다음 중 하나다.

1. 신호 자체를 바꾼다 — 감성 강도 해상도(현재 실질 6단계 범주형), 종목추출 정밀도,
   시황 기사·정형 공시 필터가 이미 미뤄둔 후보다.
2. 음의 부호가 재현되는지 본다 — 표본을 늘리거나, 국내 언론 공백이 없는 구간
   (2026-01~02, 08~09)만으로 다시 재서 부호가 유지되는지 확인한다.
3. 예측력이 없다는 결론을 받아들이고 다른 축(섹터 점수, 재무)에 무게를 옮긴다.
